## 单元和旧路径

- **7 项新增单元检查通过**：八组展开/合法组合、八组相同 S0 及初始化 RNG 保护、非均衡类别计数的客户端等权均值、零均值有效/无样本无效、原始 MSE 与梯度/缺类归约、ReLU 前特征、上一轮库校验、只采最后 epoch、F 禁用、裁剪禁用、诊断/零系数不改变参数和 RNG。
- **冻结 bdd821c 的低秩 CE＋F 客户端训练**，在相同初始化和本批私有 loader 批次下，与新协议无原型训练比较：普通低秩参数、恢复上传和 RNG 逐元素/逐状态一致。没有用自身实现充当唯一对照。
- **155 项受影响旧路径回归通过**：原多群组/预热、SVD/初始化、群组 Cosine/MSE/Z2/raw_mean、KD、旧单目标 Projection/Softmax/Z2/replay、Prox/head L2 和启动器。旧群组包、原型算法和初始化的既有冻结参照测试继续通过。

## 真实入口合成 smoke

`verify_single_avg_proto.py` 调用实际 `main.py`，使用新建专属合成分片；20 客户端、K1、原宽度 16 的 Hyper_CNN_512、100 类输出、每次 local5、两轮，完成八组及零系数/诊断关闭共 10 个用例。

| 检查 | 结果 |
|---|---|
| 八组初始服务器参数和 schema | 完全一致 |
| 八组实际数据文件及解码指纹 | 完全一致 |
| 八组同客户端/轮实际批次 | 完全一致 |
| 同一训练路径的终态 RNG | 一致；不要求完整/低秩路径彼此相同 |
| 原型开启/关闭首轮上传 | 每对实验完全一致 |
| 零系数 vs 无原型 | 本地参数、聚合参数、批次、RNG、主指标一致 |
| 原型诊断开/关 | 本地参数、聚合参数、批次、RNG、主指标一致 |
| 每用例训练预算 | 40 次客户端训练、200 前向/反向/SGD、500 次样本访问 |
| 07/08 不裁剪 | **0 次 clip_grad_norm_ 调用** |
| 05/06 完整模型 | **0 次分解，1 次初始化恢复；之后 0 次恢复** |
| 原型最后 epoch 计数 | 每客户端等于自身 train_samples，全轮合计 50，而不是五个 epoch 的 250 |
| 原型来源 | R1 无 MSE、轮末生成库；R2 只使用 R1 库；与独立等权公式一致 |
| 模型 Avg | 与独立训练样本加权和在浮点容差内一致，使用既有聚合核 |
| 全员主指标 | 用不等测试样本量独立复算 correct/samples，通过 |
| 导出 | CSV/JSON/H5/manifest 主指标和预算一致，每用例 21 个模型重载预测一致 |

模型加权和检查使用 `rtol=2e-6, atol=1e-7`，允许原核归一化及累积顺序产生的浮点差异。初始化、配对训练轨迹、零系数/诊断隔离、原型独立合并和 checkpoint 重载仍要求严格相等，没有为它们放宽容差。

低秩路径保留原下载 SVD 构造器的 RNG 消耗；完整模型跳过这些操作，故其全局 Torch RNG 不必相同。本批仅用独立私有 loader 保证八组数据顺序配对，不伪造 SVD 操作来补齐随机数消耗，不改变旧实验随机协议。

验收工具初次调用的“禁用原型”断言曾 patch 错模块中的局部导入，修正测试工具后重跑了受影响用例。跨完整/低秩路径的终态 RNG 相同断言也已改为正确的“批次相同、各路径内 RNG 一致”；没有改算法或停止梯度来通过验收。
