新增测试具体检查：

1. `base_output` 与原真实 base 输出逐元素一致，含负值；`classifier_input` 与真实 fc3 输入一致。一次训练前向，state_dict、预测不变，hook 退出移除。
2. 原始特征 MSE 按有效样本及实际维度归约，目标范数固定，目标无梯度；没有先单位化学生特征，没有额外 1/2。
3. Z2 损失与直接 `mean(z**2)` 逐元素一致，其自动微分梯度与同一直接表达式逐元素一致；和解析 `2*z/(B*d)` 的比较只容许 float64 算术顺序舍入（rtol=5e-16、atol=1e-17），不放宽旧 CPU 参数等价标准。
4. 单位化向量上的 MSE 与 `2/d * mean(1-cos)` 符合 float64 恒等式，独立防止误把原始特征 MSE 换成归一化特征 MSE。
5. MSE/Cosine 目标停止梯度，辅助项给骨干有效梯度，不给 fc3 产生直接辅助梯度；CE 与 F 仍通过原 `_objective()`。
6. 全无效 batch 可微零，非有限特征／目标／损失失败；Z2 不需要标签或原型。
7. Z2 采集、合并、packet 编解码被替换为“调用即失败”，实际训练仍通过；每 SGD batch 仅一次 forward。
8. 三种新损失零系数均与固定 `d213477` 无辅助训练参数、恢复上传及 RNG 逐元素／指纹一致，且禁止特征 hook 和采集。
9. 默认启用 Cosine 与固定 `d213477` 原 train + 原 Session 的参数、恢复上传及 RNG 严格一致。
10. 三种损失 diagnostics 0/1 的参数、实际原型 packet 和 RNG 一致。裁剪诊断直接读取原单次 clip 返回值，强制触发裁剪的测试核对平均范数与比例。
11. 原型采集与学生特征位置一致；错配明确拒绝。非法参数／被忽略的非默认目标范数／Z2 采集配置明确拒绝。

裁剪触发诊断另测了 float32 边界：当原张量计算的系数舍入为 1 时不计为触发，避免 Python float 的更高精度计算误报。这里只读取原裁剪返回值，未修改裁剪或梯度。

## 真实入口两轮合成验收

入口：`system/verify_multi_group_proto_losses.py`。独立输出：`system/temp/multi_proto_losses_acceptance_20261028/`。

**八个案例及最终跨案例对照 PASS**。完整逐案例收据及跨精度诊断见该目录 `acceptance_report.json`。固定默认 Cosine 的参数／上传／聚合／batch／RNG、原型 packet 均严格回归；零系数和诊断开关的严格对照通过。逐列旧聚合核最大参数误差为 0。

第二轮相同下载起点、相同 base_output 的 Cosine/MSE 原型库指纹完全一致。两者各采集 150 个样本前向／90 批，上传统计 `24,614,106` 字节、单份库 `1,231,232` 字节、下发 20 人共 `24,624,640` 字节；分别耗时约采集 4.88/4.92 秒、合并 .302/.316 秒。仅为本机微型合成数据的实测；Z2 对应各项为 0。SGD 的 1500 次训练样本访问与这些采集量分开记录。

使用真实 `main.py`、N20、K3、原宽度 16 的 `Hyper_CNN_512`、五档原容量、rank .15 低秩恢复初始化、7/7/6 full_weights 分组、两个真实 SGD 训练／聚合轮次、每模型 5 epoch。合成数据每客户端 train 2/3 张、test 1/2/3/4 张，专门覆盖不等测试样本量。

八个案例：固定 d213477 无辅助参照、MSE 零系数、固定 d213477 原 Cosine、当前默认 Cosine、base_output Cosine、base_output MSE、base_output Z2、Z2 diagnostics 关闭。

每例 120 次模型训练任务、600 次 SGD step、1500 次训练样本访问；这些是微型合成数据的实际量，不能代替真实 CIFAR-100 开销。原型有效例仅第二轮额外采集 150 个样本前向、90 批；Z2 和零系数为 0。

核对内容：

- 固定原版与默认 Cosine 的上传／服务器参数、batch 及 RNG 严格一致；同时核对实际原型 packet 指纹和字节数。
- MSE 零系数与原无辅助入口严格一致。
- 八例初始化、首轮上传、首轮分组、batch 序列和最终 RNG 一致；首轮不受辅助项影响。
- 每列对相同恢复上传独立调用旧群组聚合核，要求最大参数误差为 0，不放宽容差。
- 全员、群组、容量样本量加权指标独立复算，best 是同轮曲线最大值，最早轮次及 last10/last20 点数正确。
- 原型有效例全体 60 个本地模型先采集、后任意 SGD；采集前后模型和 RNG 不变。
- Z2 无原型来源／采集／上传／库文件，通信与采集量为 0；全 60 个本地模型辅助项生效。
- JSON、CSV、H5、持续 JSONL 与 manifest 一致；实际三份服务器和 60 份普通低秩 checkpoint 重载预测一致。
- 同一 Z2 的 diagnostics 开关下，上传、聚合、batch、RNG 与主指标不变。
